# QA Checklist: Restful Booker Platform

## 1. UI & Navigation Testing
* [ ] Главная страница загружается корректно без критических визуальных артефактов.
* [ ] Пункты меню (Rooms, Booking, Amenities, Location, Contact, Admin) корректно перенаправляют или скроллят страницу.
* [ ] Карточки комнат отображают актуальную информацию (название, описание, удобства, цена).

## 2. Contact Form (Форма обратной связи)
* [ ] Валидация полей (Name, Email, Phone, Subject, Message) работает при попытке отправки пустой формы.
* [ ] Ограничения длины/формата полей (например, минимальная длина темы сообщения) соблюдаются.
* [ ] Успешная отправка валидных данных отображает сообщение благодарности («Thanks for getting in touch...»).

## 3. Room Booking (Бронирование)
* [ ] Доступен выбор дат через календарь.
* [ ] Кнопка бронирования реагирует на действия пользователя.

## 4. Admin Authentication
* [ ] Страница логина администратора открывается по ссылке Admin.
* [ ] Валидация пустых полей ввода логина и пароля.
* [ ] Поведение системы при вводе неверного пароля.
